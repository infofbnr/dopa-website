# Dopa — teen wellness website prototype

A responsive HTML/CSS/JavaScript prototype based on the supplied Dopa concept PDF.

## Run
Open `index.html` in a modern browser. No build tools or server are required.

## Included interactions
- First-visit onboarding and display-name setup
- Dashboard with points, manually logged screen time, progress ring and nudges
- Offline quests with category filters and completion rewards
- Mood check-ins, reflection prompts and local mood history
- Community meetup interest toggles
- Reward redemption using earned points
- Settings, screen-time goal, guardian acknowledgement and local demo-data reset
- Responsive sidebar/navigation and modal dialogs

## Important prototype limitations
This is a front-end demo. Data is stored in browser `localStorage`; it is not encrypted or synced. Screen time is entered manually. There is no real AI connection, account system, OTP, guardian identity verification, wearable integration, push notifications, community moderation, or real coupon issuance. The wellness language is supportive and non-diagnostic. Do not use this prototype to collect sensitive information from real teenagers.
